# 🌍 Interactive WebGIS Map from QGIS using QGIS2Web

> A practical GIS project demonstrating how a QGIS project can be transformed into an interactive browser-based WebGIS application using the QGIS2Web plugin.

---

## 📌 Project Overview

This project demonstrates the workflow of preparing GIS data in **QGIS**, organizing and styling spatial layers, and publishing the resulting map as an interactive WebGIS application using the **QGIS2Web** plugin.

The workflow connects desktop GIS with web-based visualization, allowing spatial data to be explored through an interactive browser interface.

The project focuses on practical GIS skills including layer management, cartographic styling, WebGIS export, interactive map controls, and web-based spatial visualization.

---

## 🎯 Project Objectives

The main objectives of this project are to demonstrate a complete QGIS-to-WebGIS workflow:

* 🗺️ Manage and organize GIS layers in QGIS
* 🎨 Apply appropriate symbology and layer styling
* 📊 Prepare spatial data for web visualization
* 🔌 Configure and use the QGIS2Web plugin
* 🌐 Export the QGIS project as an interactive WebGIS
* 🧭 Implement interactive map navigation
* 🔎 Enable interactive feature information
* 🖥️ Test the generated WebGIS in a browser
* ⚙️ Understand the structure of the exported web application
